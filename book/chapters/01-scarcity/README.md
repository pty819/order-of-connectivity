# 第一章：稀缺的连接

这一章从有限通信怎样成为可用服务写起。技术容量只是条件之一：资金、地方建设、组织权限、设备和工程人员决定网络如何扩展，申请与收费又决定谁能够进入。邮电体系既是建设和服务组织，也承担跨地区协调；其内部已有不同经营责任和财务渠道，不能被一个不变的“国家垄断”概念概括。

全章围绕三个相接的过程展开：稀缺怎样被分配，扩容所需的资源怎样取得，技术与组织能力怎样形成。不同过程之间可能相互促进，也可能产生新的限制。收费可以支持建设，同时提高当期接入门槛；地方投资可以推进工程，也可能使地区条件和用户身份进入分配；设备引进可以迅速增加能力，却不必然带来同样充分的技术学习。

正文以1978—1993为重心，前史和后续仅在解释机制时进入。国家文件、同期工程与财务资料、地方志、参与者回忆及学术研究分别使用。回忆和地方总结提供线索及解释，不能独自决定全国因果；统计中的容量、话机、用户、线路和自然人数也须分别辨认。
