# 交换、传输与本地接入的分工

第一章·1.7.1。电话用户面对的是一次联系，建设和经营体系面对的却是多个相互依赖环节。本地接入把终端带入网络，交换组织接续，传输连接不同节点。本节主张，早期供给不足不能简单归为电话机或交换门数太少，重要问题还在于各环节怎样匹配。功能分工也参与形成投资、责任和收入的组织边界。

## 一次服务为什么不是一台设备的产出

用户有话机，尚需线路接入；交换局有容量，尚需到另一地点的通路和对端条件。下面是功能示意，不代表任何年份真实路由，也未展开长途网内部层级。

```mermaid
flowchart LR
 A[主叫终端] --> B[本地接入]
 B --> C[交换接续]
 C --> D[节点间传输]
 D --> E[对端交换]
 E --> F[对端接入]
 F --> G[受话终端]
```

图中任一项必要条件缺少，都可能影响这一联系，但不能据此给整个多路径网络套一个固定最小容量公式。实际系统有路由、时段和不同业务，瓶颈会随使用条件改变。功能示意的意义在于使相互依赖可见，而不是代替历史拓扑。

这使技术能力具有关系性。某台设备在测试中达到指标，只证明相应对象；同其他部分配合以后，才形成用户所需服务。将设备规模直接当成社会供给，便跨过了最需要解释的组织过程。

## 同期评估发现了什么不匹配

世行1993年评估记述，地方接入电缆发展落后于交换设备，部分已装容量未能连接用户，并将地下工程复杂和资金安排列为相关条件。[^R0224]这是同期观察者对一个具体问题的解释，不是所有闲置的统一原因。

它使扩容与等待能够同时得到理解。中心设备取得较快，分散在道路和建筑中的线路较慢，前者便不能立即转成新增用户。项目之间的资源和权限不同，技术上互补的部分未必在投资上同步。

这也解释为什么简单追加主机，未必有同样边际效果。若限制在外线和配线，补齐它们可能比继续增加中心容量更直接形成服务。反过来，线路已经具备而交换不足时，次序又不同。历史选择要放回当时瓶颈，而不是按单项技术先进程度排列。

## 聊城的割接为何包含外线改造

聊城1988年自动电话工程割接，同时改造主干电缆、配线区和配线箱，后续又因部分地区分布不能满足需要继续施工。[^R0257]自动交换没有取消本地网络，反而要求其结构同新设备相接。

配线把全市能力放到具体街区，末端线路再将其交到用户。两者既有技术关系，也有时间和空间选择。某地总量较多，不表示每处地址都有同等现成条件；一个局能提供新业务，也需要对应线路和办理。

这一案例为设备史补上了另一类劳动。更换、移设、配线与测试往往没有主机开通同样醒目，却是新能力实际可用的条件。若叙述只留下进口和投产，技术进步就会显得不需要城市工程。

## 地方与全国的分工怎样相接

1993年评估将跨省干线和地方扩展分别安排实施主体。[^R0224]这同功能相互依赖有关：地方掌握末端和本地条件，国家专业组织处理更大通路，但两者不能各自完成后便假定服务自然成立。

一省的本地用户可能依赖邻省接续，骨干经过一地也要有本地接口才能服务居民。吴基传回忆的干线瓶颈，正说明局部扩张还会把新的压力传到其他环节。[^R0165]用户增加会改变对传输和对端的要求，瓶颈不是一劳永逸的位置。

分工因此需要共同资料、标准和时序，也需要结算承认各环节贡献。前面的内部核算并非附在技术之外，它回应的正是收款和生产分布不同。技术与财务组织，在这里有共同基础。

分工还使资源取得速度不同。交换设备可以相对集中地采购、安装和测试，本地线路则分散进入道路、建筑与不同地址。前者的合同和交付较容易作为一个项目出现，后者需要多次现场决定。两者技术上互补，组织上却不必同速，评估所记接入滞后正应放在这一差别中理解。

由此，某地有设备而尚未充分接入，不能只被写成缺少经营意识。资金、地下施工和配线需要不同主体，协调困难可能造成真实等待；但这也不能成为不再追责的理由。应当沿每项决定辨认可控制部分，而非把一切归于自然技术限制。

用户只看到完整通话成功或失败，内部组织则按段完成任务。两种视角之间可能出现责任缺口：每处设备都声称正常，整体服务却仍不稳定。共同测试、故障资料和跨环节处理，使局部指标有可能回应最终服务。它们不只增加管理费用，也是专业分工能持续成立的条件。

这说明基础设施经济性不只是规模扩大后单项成本下降。接口、协作和互补资源也会影响结果；分工过细而无法相接，可以使已经形成的能力不能充分利用。技术史需要将这种组织成本与机器性能放在一起，而不把前者都归为技术之外的干扰。

## 指标怎样改变建设的可见性

门数、通路、话机和线路长度分别记录不同对象。容易集中采购和统计的设备，可能比遍布城市的配线更显眼；全局总量又比局部接入困难容易成为成绩。指标选择由此可能影响管理注意力。

这不是说数量指标没有价值。它们能够组织大规模建设，但需要保持对象，才能用于比较。用某项增长证明全部服务同步改善，会让尚未匹配的环节从叙述中消失；只讲用户一次失败，也不能说明所有能力没有作用。

本节因此把网络扩张理解为互补能力不断重新配对的过程。新增一环可以解决旧限制，也可能显出下一环需要。技术分工、投资次序和责任安排共同决定其结果，这比一串设备增长数字更能解释通信何时真正变得可用。
