# 数量史料与口径

`greatwall-costs-2010-2012.csv` 是 R0047 原始表的有限数字摘录，单位为万元人民币，实体为长城宽带网络服务有限公司，范围为主营业务成本。

- 2010、2011为全年；2012只含1—8月，未年化。
- 百分比保留原表两位小数，金额按原表万元取值；金额合计已核对，百分比允许四舍五入。
- 印刷页为1-1-65，PDF页为66，两者不是同一页码体系。
- “出口租金”按报告解释包含租赁带宽和专项租赁成本，不统一解释为国际出口。
- 来源是收购方公开披露的财务材料，计算核对不替代原始审计或经营解释。

数据用于有限的成本结构比较，不直接证明供应商歧视、违法利润挤压、网络超售或具体故障原因。
