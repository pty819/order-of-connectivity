# 数量史料与口径

`greatwall-costs-2010-2012.csv` 是 R0047 原始表的有限数字摘录，单位为万元人民币，实体为长城宽带网络服务有限公司，范围为主营业务成本。

- 2010、2011为全年；2012只含1—8月，未年化。
- 百分比保留原表两位小数，金额按原表万元取值；金额合计已核对，百分比允许四舍五入。
- 印刷页为1-1-65，PDF页为66，两者不是同一页码体系。
- “出口租金”按报告解释包含租赁带宽和专项租赁成本，不统一解释为国际出口。
- 来源是收购方公开披露的财务材料，计算核对不替代原始审计或经营解释。

数据用于有限的成本结构比较，不直接证明供应商歧视、违法利润挤压、网络超售或具体故障原因。

## 设备价格与收入分布演示

`device-price-income-2025.csv`采用R0122国家统计局2025年公报第九节的五等份收入组原值。分组依据见公报注64：调查户按家庭人均收入排序分为五等份；组均值不是分组界限，也不是20%个人劳动者的工资。

- `annual_per_capita_disposable_income`是各组年度人均可支配收入，单位人民币元。
- `hypothetical_device_price`统一假设3000元，非实际设备均价、品牌报价或购买记录。
- `price_income_percent`为假设价格除以收入再乘100，以Decimal计算、四舍五入保留两位小数。
- 比值只展示同一价格与收入分布的关系，未计家庭规模、必要支出、储蓄、债务、服务费用和设备寿命，不是可负担率、劳动月数或实际购买概率。
