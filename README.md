# 连接的秩序

**The Order of Connectivity: Telecommunications and the Making of Modern China**

一部正在研究、写作与公开修订的中文技术史／社会经济史著作。以改革开放以来的通信网络为观察窗口，研究国家机构、基础设施产权、市场竞争、技术标准、产业资本和普通人的生活如何相互塑造。晚清至计划经济时期作为必要的制度背景，主体研究范围暂定为 1978—2026 年。

本项目沿着原研讨提出的主题依次查证和写作，最终整合成连续的历史叙事。支持有解释力的判断，也允许史料推翻最初的观点。**当前版本是研究初稿，尚未完成全部主题，也未经外部学术审稿。**

## 文件组织

```text
book/                 连贯叙事；大章节下分小专题 Markdown
references/           文献元数据、公开地址、核验范围
research/             主题顺序、证据关系、纠错、研究记录
scripts/              引用与结构检查、史料本地获取工具
.research-cache/      本地史料副本与获取日志，不公开提交
```

正文以 `[^R0001]` 等稳定编号引用文献；每篇末尾列出可点击的出处和具体定位。CSV 使用 UTF-8，含表头。网络页面的入库不是证据核验完成的同义词；文献表明确区分全文、摘要、目录及获取失败。

## 核查

```sh
python3 scripts/validate.py
```

此检查只验证引用编号、CSV 关联和本地链接，不能替代史料批判、历史事实核查或同行评议。项目目前不配置 CI/CD。

修订史料大纲CSV或相关文献定位后，可用`python3 scripts/build_source_outline.py`重新生成可读大纲，再执行核查，避免两个版本漂移。
