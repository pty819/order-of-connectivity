# 连接的秩序

**The Order of Connectivity: Telecommunications and the Making of Modern China**

一部正在研究、写作与公开修订的中文技术史／社会经济史著作。以改革开放以来的通信网络为观察窗口，研究国家机构、基础设施产权、市场竞争、技术标准、产业资本和普通人的生活如何相互塑造。晚清至计划经济时期作为必要的制度背景，主体研究范围暂定为 1978—2026 年。

本项目沿着原研讨提出的主题依次查证和写作，最终整合成连续的历史叙事。支持有解释力的判断，也允许史料推翻最初的观点。**当前版本是研究初稿，尚未完成全部章节的扩写及补证，也未经外部学术审稿。**

## 文件组织

```text
book/                 十章阅读目录、写作方案与既有专题 Markdown
references/           文献元数据、公开地址、核验范围
research/             主题顺序、证据关系、纠错、研究记录
scripts/              引用与结构检查、史料本地获取工具
.research-cache/      本地史料副本与获取日志，不公开提交
```

正文以 `[^R0001]` 等稳定编号引用文献；每篇末尾列出可点击的出处和具体定位。CSV 使用 UTF-8，含表头。网络页面的入库不是证据核验完成的同义词；文献表明确区分全文、摘要、目录及获取失败。

## 核查

```sh
python3 scripts/validate.py
```

此检查只验证引用编号、CSV 关联和本地链接，不能替代史料批判、历史事实核查或同行评议。项目目前不配置 CI/CD。

修订史料大纲CSV或相关文献定位后，可用`python3 scripts/build_source_outline.py`重新生成可读大纲，再执行核查，避免两个版本漂移。

修订十章方案CSV后，用`python3 scripts/build_chapter_plan.py`生成写作方案与目录。章号按新目录识别，旧专题目录路径是研究阶段的存储位置。

小节问题、内部话题、叙事、史料入口与补证见`research/section-outline-v1.csv`。同一生成脚本据小节表同步章级节次，并生成详细大纲；小节交叉引用及史料阅读状态也纳入结构核查。

上一轮对照学术研究与参与者回忆，新增52个小节、加深38个原节；文献表增加39条记录，分别标明指定节段、摘要、目录及书摘。来源如何改变大纲见`research/outline-expansion-v2.csv`及可读记录。

第三轮在十章各新增2节，并加深20个原节；新增160个内部话题附具体写作说明，新增19条文献记录。补入人工接续劳动、城市施工、企业后台与债务、普通企业托管、互联测量、商用测试、基站选址、渠道信用、召回、学校与家庭管理、工艺学习、SIM卡采购、旧工业协议和海外运营。具体缺口与已读范围见`research/outline-expansion-v3.csv`及可读记录。回忆录原书、公开转引、访谈、论文全文指定页和摘要分别注明，不将入库数量当全文阅读数量。

小节ID是永久锚点，显示编号随编排调整，已有链接继续指向原主题。内部话题说明在小节总表的`subtopic_notes`字段登记，由同一脚本生成。

第一章正文文件名按阅读小节号命名：例如1.4.1对应`ch01-s04-t01.md`，1.5.1对应`ch01-s05-t01.md`。清单里的永久ID用于史料关联，实际文件路径与显示节号一致；目录调整时同步迁移路径并核对全部引用。
